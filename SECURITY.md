# Política de Segurança (Security Policy)

A segurança dos usuários e a integridade do código do **DivinoGIS** são levadas a sério.

---

## Versões Suportadas

Atualmente, fornecemos suporte de segurança para a versão ativa na branch `main`:

| Versão | Suportada? |
| :---: | :---: |
| `main` (latest) | :white_check_mark: Sim |
| < 1.0.0 | :x: Não |

---

## Como Reportar uma Vulnerabilidade

Caso descubra uma falha ou vulnerabilidade de segurança:

1. **Por favor, NÃO abra uma Issue pública** para relatar problemas críticos de segurança.
2. Utilize a funcionalidade oficial de **Relatório de Vulnerabilidade Privada** do GitHub:
   - Vá na aba **Security** do repositório ➔ **Advisories** ➔ **Report a vulnerability**.
3. Inclua o máximo de detalhes possível:
   - Descrição da vulnerabilidade encontrada.
   - Passos reproduzíveis ou Prova de Conceito (PoC).
   - Possível impacto.

Agradecemos antecipadamente por colaborar com a segurança da comunidade de código aberto!
